Price Analysis Platform

Initial scaffold for the Price Analysis Platform.

This repo contains a .NET backend scaffold and a plan to build a price-analysis system that ingests product pricing, stores history, and computes recommendations.

Quick start (backend):

```bash
cd src/backend/PriceAnalysis.Api
dotnet build
dotnet run
```

Next steps: scaffold frontend, add EF Core models, and implement ingestion workers.
